# Archive

Historical files retained for reference live here instead of cluttering the active site structure.

`legacy/` contains superseded snapshots and old loose assets that were previously stored at repository root.

Do not link public pages to files in this directory. Active code and assets belong under `index.html`, `assets/`, `content/`, or `data/`.

Git history remains the authoritative record of every version; this folder is only for recognizable legacy files that are still useful to inspect directly.
