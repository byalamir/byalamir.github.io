# Content

This directory is the source archive for work published or represented by BY ALAMIR.

Collections:

- `writing/` — essays, criticism, commentary, and general long-form work
- `research/` — psychology, sociology, frameworks, papers, and research-led pieces
- `lvrs/` — LVRS Radio editorials, playlists, reviews, release coverage, and music notes
- `elfa/` — ELFA fashion concepts, collections, garment notes, identity work, and product development
- `projects/` — multidisciplinary work that does not fit cleanly into one collection

## Entry rule

Each substantial item should eventually get its own slug folder, for example:

`content/research/recursive-reality-enclosure/`

Inside that folder, keep the source text and any item-specific notes. Register the item in `/data/content-index.json` so the website can discover, filter, and search it later.

Use `content/_template.md` as the starting point for new entries.
